Navegação Pensada para Todos

Este site foi desenvolvido seguindo as diretrizes internacionais de acessibilidade (WCAG). Ele possui estrutura semântica clara para leitores de tela, contraste ajustável para pessoas com baixa visão e controles simples que funcionam totalmente pelo teclado.

Como usar os recursos

  • Tecla Tab: Navegue entre botões e links com destaque visual claro.
  • Botões A+ e A-: Aumente ou diminua o tamanho das letras conforme sua necessidade.
  • Alto Contraste: Altera as cores para fundo preto com texto amarelo, reduzindo o cansaço visual.
  • Ouvir Texto: O navegador lê o conteúdo principal em voz alta em português.
